📚 Book Selling System – Java (Swing + MySQL + JDBC)

A desktop-based Book Selling / Inventory Management System built using Java, Swing GUI, JDBC, and MySQL.
This project demonstrates OOP concepts, GUI development, database connectivity, CRUD operations, and proper application structuring in Java.

🚀 Features
🔹 Book Management

Add new books

Update book details

Delete books

View all books

Search books by name / ID

🔹 Sales Management

Sell books

Generate bill (simple text output)

Update stock after sale

🔹 Database Integration

MySQL database using JDBC

Proper connection handling

Prepared statements for safe queries

🔹 User Interface (Swing)

Clean Swing form

Buttons, tables, labels, text fields

Scrollable book list

Easy navigation

🛠️ Tech Stack
Technology	Purpose
Java (Core + OOP)	Application logic
Java Swing	GUI / Frontend
JDBC	Database connectivity
MySQL	Backend database
MVC Pattern (Recommended)	Clean project structure
